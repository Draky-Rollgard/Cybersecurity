# 49. Dicionário

| Termo | Definição |
|---|---|
| **ARP** | Address Resolution Protocol; associa endereços IPv4 a endereços MAC. |
| **ACK** | Acknowledgment; confirmação utilizada principalmente pelo TCP. |
| **Anycast** | Comunicação em que o pacote é direcionado a um membro adequado de um conjunto de endereços. |
| **ARP Request** | Mensagem usada para descobrir o MAC associado a um IPv4. |
| **ARP Reply** | Resposta contendo a associação IP/MAC solicitada. |
| **Broadcast** | Comunicação enviada para todos os hosts de determinado domínio de broadcast. |
| **Checksum** | Valor usado para detectar alterações/corrupção nos dados protegidos. |
| **Datagrama** | Unidade de dados associada a protocolos como IP e UDP. |
| **DHCP** | Protocolo utilizado para configuração dinâmica de parâmetros de rede. |
| **DNS** | Sistema/protocolo utilizado para resolução de nomes. |
| **Ethernet** | Tecnologia de rede utilizada principalmente nas camadas Física e de Enlace. |
| **FIN** | Flag TCP utilizada para indicar encerramento de fluxo/conexão. |
| **Frame** | Unidade de dados da camada de enlace. |
| **Fragmentação** | Divisão de um datagrama IP em fragmentos menores. |
| **Guest** | Sistema operacional executado dentro de uma máquina virtual. |
| **Host** | Dispositivo ou sistema participante de uma rede; também pode designar a máquina física que hospeda uma VM. |
| **HTTP** | Hypertext Transfer Protocol; protocolo usado na Web. |
| **ICMP** | Internet Control Message Protocol; protocolo utilizado para mensagens de erro, controle e diagnóstico IP. |
| **IGMP** | Internet Group Management Protocol; gerencia participação em grupos multicast IPv4. |
| **IP** | Internet Protocol; fornece endereçamento lógico e encaminhamento de pacotes. |
| **IPv4** | Versão 4 do IP, utilizando endereços de 32 bits. |
| **IPv6** | Versão 6 do IP, utilizando endereços de 128 bits. |
| **IHL** | Internet Header Length; tamanho do cabeçalho IPv4. |
| **ISO** | Imagem de disco usada para distribuição/instalação de sistemas. |
| **MAC Address** | Endereço físico associado à interface de rede na camada de enlace. |
| **Multicast** | Comunicação destinada a um grupo específico de receptores. |
| **NAT** | Network Address Translation; mecanismo de tradução de endereços de rede. |
| **Netinstall** | Imagem de instalação enxuta que obtém pacotes adicionais pela rede. |
| **OSI** | Open Systems Interconnection; modelo conceitual de sete camadas para redes. |
| **Payload** | Conteúdo transportado dentro de uma unidade de dados de protocolo. |
| **PING** | Ferramenta de diagnóstico que normalmente utiliza ICMP Echo Request/Reply. |
| **Porta** | Identificador lógico utilizado para direcionar tráfego a processos/serviços. |
| **Protocol Field** | Campo IPv4 que identifica o protocolo encapsulado na camada superior. |
| **Root** | Usuário administrativo privilegiado em sistemas Unix/Linux. |
| **Router/Roteador** | Dispositivo que encaminha pacotes entre redes. |
| **Segmento** | Unidade de dados associada ao TCP. |
| **SHA-256** | Função hash criptográfica que produz uma saída de 256 bits. |
| **Socket** | Endpoint de comunicação associado a endereços e portas; em sentido amplo, representa a interface de comunicação de um processo. |
| **Snapshot** | Estado salvo de uma máquina virtual que permite retornar a uma configuração anterior. |
| **SYN** | Flag TCP usada para iniciar/sincronizar uma conexão. |
| **TCP** | Transmission Control Protocol; protocolo de transporte orientado à conexão e confiável. |
| **TCP/IP** | Suíte de protocolos utilizada para comunicação em redes, incluindo a Internet. |
| **TTL** | Time To Live; campo IPv4 usado para limitar a quantidade de saltos de um pacote. |
| **UDP** | User Datagram Protocol; protocolo de transporte sem conexão e com baixo overhead. |
| **Unicast** | Comunicação de um remetente para um destinatário. |
| **VM** | Virtual Machine; máquina virtual. |
| **VirtualBox** | Software de virtualização utilizado para criar e administrar VMs. |
| **VT-x** | Tecnologia Intel de suporte à virtualização por hardware. |
| **AMD-V** | Tecnologia AMD de suporte à virtualização por hardware. |
| **Wireshark** | Analisador de protocolos capaz de capturar e inspecionar tráfego de rede. |
| **Well-known Port** | Porta da faixa 0–1023 tradicionalmente associada a serviços padronizados. |
| **Three-way Handshake** | Processo TCP de três etapas: SYN → SYN/ACK → ACK. |
| **FSM** | Finite State Machine; máquina de estados finitos usada para representar estados e transições de protocolos. |
| **Encapsulamento** | Processo de adicionar informações de controle de uma camada aos dados recebidos da camada superior. |
| **Desencapsulamento** | Processo inverso, em que cada camada remove/processa as informações destinadas a ela. |
| **Overhead** | Dados adicionais necessários ao funcionamento de um protocolo, além do conteúdo útil. |
| **Controle de fluxo** | Mecanismo que evita que um transmissor envie mais dados do que o receptor consegue processar. |
| **Controle de congestionamento** | Mecanismos do TCP destinados a adaptar a transmissão às condições da rede. |
| **Roteamento** | Processo de determinar e utilizar caminhos para encaminhar pacotes entre redes. |
| **Endereço lógico** | Endereço utilizado na camada de rede, como um endereço IP. |
| **Endereço físico** | Endereço utilizado na camada de enlace, como um MAC Ethernet. |
| **Camada de aplicação** | Camada TCP/IP que fornece protocolos utilizados diretamente por serviços de rede. |
| **Camada de transporte** | Camada responsável pela comunicação entre processos e pelo uso de TCP/UDP. |
| **Camada Internet** | Camada responsável pelo endereçamento IP e encaminhamento entre redes. |
| **Camada de acesso à rede** | Camada responsável pela comunicação sobre a tecnologia física/enlace utilizada. |
